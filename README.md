# AB Gaming Studios

Cursor'da devam etmek için:

1. ZIP dosyasını aç.
2. Cursor'da **File > Open Folder** ile `AB-Game-Studios-Cursor` klasörünü seç.
3. Ana sayfa `index.html` dosyasıdır.
4. Ortak tasarım `assets/styles.css`, menü yapısı `assets/site.js` içindedir.

## Sayfalar

- `index.html` — Anasayfa
- `hakkimizda/index.html` — Hakkımızda
- `oyunlar/index.html` — Oyunlar
- `haberler/index.html` — Haberler
- `iletisim/index.html` — İletişim

## Yerel önizleme

Cursor terminalinde şu komutu çalıştır:

```bash
python3 -m http.server 5500
```

Ardından tarayıcıda `http://localhost:5500` adresini aç.

Not: İletişim formu şu an yalnızca görsel prototiptir. E-posta gönderimi için daha sonra bir servis veya backend bağlanmalıdır.
